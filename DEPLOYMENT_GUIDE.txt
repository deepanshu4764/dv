  $ git remote add origin https://github.com/YOUR_USERNAME/deepanshuventures.git

STEP 3: Deploy to Vercel
────────────────────────
  Option A: Using Web (Recommended)
  ─────────────────────────────────
  1. Go to https://vercel.com
  2. Click "New Project"
  3. Import your GitHub repository
  4. Vercel auto-detects vercel.json
  5. Click "Deploy"
  6. 🎉 Done! Your site is live

  Option B: Using CLI
  ───────────────────
  $ npm install -g vercel
  $ vercel login
  $ cd "c:\Users\earth\Desktop\deepanshu ventures"
  $ vercel
  $ vercel --prod  # Deploy to production

To set on Vercel:
1. Go to https://vercel.com/dashboard
2. Select your project → Settings → Environment Variables
3. Add each variable
4. Redeploy: $ vercel --prod

Issue: Links not working locally
Fix: Make sure you're visiting http://localhost:8000 (with port)

Issue: Social Drive backend not responding
Fix: Check if npm start is running in social-drive folder

Issue: Vercel deployment fails
Fix: 
  1. Check vercel.json is valid JSON
  2. Ensure all required files are committed to git
  3. Check build logs on Vercel dashboard

Issue: Environment variables not working
Fix: Redeploy after adding env vars: $ vercel --prod
